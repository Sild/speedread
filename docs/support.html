FastReader Support

FastReader is a local-first EPUB and PDF reader for iPhone and iPad. Import and reading continue offline; optional EPUB synchronization uses the private iCloud database of the signed-in Apple account.

Get help

Report a problem, ask a question, or request an improvement through the public FastReader support tracker. Do not attach copyrighted books, account details, or private documents.

Useful details

Include the FastReader version, iPhone or iPad model, iOS version, file type, and the exact visible error.

  • Supported imports: DRM-free EPUB and password-free PDF.
  • Protected EPUB and password-locked PDF files are intentionally rejected.
  • PDF files and OCR results remain on the device and never sync through FastReader.
