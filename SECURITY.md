# Security Policy

## Supported versions

Security fixes target the current App Store release and the latest `main`
branch. Older releases may require updating to receive a fix.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
[silddev@pm.me](mailto:silddev@pm.me) with:

- a concise description and potential impact;
- affected versions or commits;
- reproduction steps or a proof of concept;
- any suggested mitigation;
- whether the report is under coordinated disclosure.

Do not include real user data, copyrighted publications, credentials, signing
material, or destructive payloads. You should receive an acknowledgement within
seven days. Please allow time to investigate and ship a fix before public
disclosure.

For ordinary bugs and product support, use the public issue templates or the
[support page](https://sild.github.io/speedread/support.html).
